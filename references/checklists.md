# 校招行动 Checklist（按阶段）

来源：2026-09-17 HR 分享会（朱宇昂）整理的行动清单，去掉已过时条目，保留可复用部分。

## A. 现在立即做

- [ ] 明确 2–3 个目标岗位
- [ ] 明确目标行业与赛道
- [ ] 梳理全部项目、实习、竞赛素材（写成事实台账：时间、角色、动作、数字）
- [ ] 收集目标企业历年面经（牛客、知乎、公众号）
- [ ] 关注目标企业校招时间节点（提前批往往 6–8 月就开）
- [ ] 关注线下宣讲会（线下投递 + 现场沟通的优先级高于纯海投）
- [ ] 调研目标企业经营情况与校招舆情

> **为什么宣讲会值钱**：海量网申 HR 看不过来；线下简历更容易被单独归类，HR 有抓手向业务推动，部分企业现场安排面试，到场本身也传递求职意愿。

## B. 每投一个岗位前（约 30 分钟）

- [ ] 读完整 JD，标出前 3 项核心职责与高频关键词
- [ ] 用自己的经历逐条匹配，确认每项能力都有证据
- [ ] 调整简历顺序：最匹配的项目/实习放前面
- [ ] 补上岗位关键词（关键词 + 真实证据，不堆砌）
- [ ] 删除制造错误画像的信息
- [ ] 检查毕业年份（校招最容易致命的一项，别写"至今"）
- [ ] 检查手机号、邮箱能被机器正确识别
- [ ] 检查是否一页内表达清楚
- [ ] 用 AI 做一次 JD 匹配度检查，然后**人工改写去除 AI 味**

## C. 笔试 / 测评前

- [ ] 用 JD 反推专业考点（JD 来自业务，笔试题也来自业务）
- [ ] 搜集往年笔试题与面经
- [ ] 测评认真作答，保持前后一致，不要出现极端选项反复
- [ ] 提前熟悉考试平台（牛客等）的操作与调试功能

## D. 面试前

- [ ] 准备 1 分钟自我介绍（另备 30 秒与 2 分钟版本）
- [ ] 准备 3 个最核心项目，每个准备多轮追问
- [ ] 明确自己的真实贡献，能把团队成果与个人产出分开说
- [ ] 准备量化结果（每个项目至少 2 个可解释的数字）
- [ ] 准备"为什么这个岗位""为什么这家公司"
- [ ] 准备职业规划（短期能力 → 中期负责范围 → 长期判断力）
- [ ] 准备反问清单（按面试官层级选 2–3 个）
- [ ] 查公司一手信息：官网、产品站、招聘页、（能查到的话）高管背景与近期动态
- [ ] 调试网络、提前进入会议、整理衣着与环境

## E. 面试中

- [ ] 先说结论，再展开
- [ ] 用"一二三点"结构
- [ ] 项目按"痛点 → 打法 → 资源 → 结果"讲
- [ ] 用真实案例证明价值观，不用标签
- [ ] 不夸大没做过的事
- [ ] 不会的坦诚承认，并说明你会怎么补
- [ ] 保持互动与不卑不亢
- [ ] 观察面试官追问的重点（那就是他真正在意的能力）
- [ ] 结尾把经历关联到当前岗位

## F. 面试结束后（当天 30 分钟内）

- [ ] 立刻记录被问到的问题（按顺序）
- [ ] 记录哪题答得好、哪题答差了、下次怎么改
- [ ] 判断对方最关注的能力
- [ ] 更新个人面试题库与追问树
- [ ] 跟踪流程进度、需要的后续材料

## G. 拿到 Offer 后

- [ ] 确认 Offer 有效期与回复截止
- [ ] 确认三方要求与违约条款
- [ ] 尝试协调不同公司的流程时间，把选择集中到同一窗口
- [ ] 对比：行业前景 → 岗位可迁移能力 → 成长空间 → 薪酬 → 城市
- [ ] 调研团队稳定性与业务方向
- [ ] 综合决策并书面确认

## 附：一句话原则（背下来）

- 匹配度大于完美度
- 简历过筛 = 人才画像基本匹配
- 简历要做减法
- 面试本质是持续验真
- 你写进简历的每个环节都要经得起追问
- 所有问题先讲痛点，再讲打法，再讲资源
- 不要挤牙膏，先说结论
- 初面通过 = 专业能力基本匹配；越往后的面试越看潜力与格局
- 面试是双选
- 顶级 Offer 不是某一轮大力出奇迹，而是每一轮都不失分

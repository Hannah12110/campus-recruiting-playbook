# campus-recruiting-playbook

校招全流程方法论 —— 一个 Hermes Agent Skill。

把 2026-09-17《HR 求职分享会：校招简历面试 Offer 方法论》提炼成可执行的流程与清单，用于：

- 准备某家公司的校招面试（一面 / 二面 / HR 面 / 终面）
- 改简历、做岗位定向准备
- 拿到 Offer 后做比较与节奏管理
- 复盘面试表现、定位失分点

## 目录结构

```
SKILL.md                              # 主文件：心法、漏斗、简历、表达框架、反问分层、Offer 管理、红旗
references/checklists.md              # 分阶段行动清单（投递前 / 笔试前 / 面试前中后 / 拿 Offer 后）
references/source-2026-09-17-HR校招分享会.md   # 原始分享会整理全文（提炼依据，保留溯源）
```

## 怎么用

**在 Hermes 里**：把本目录放到 `~/.hermes/skills/career/` 下（或 `hermes skills install <repo>`，取决于你的版本），之后说"准备面试/改简历/看 Offer"时会自动加载。

**手工查**：直接读 `SKILL.md`。建议顺序是先读"核心心法"6 条 → 再看"招聘漏斗"判断当前这轮面试官在看什么 → 用"轮次分层策略"决定讲什么 → 面试前过一遍 `references/checklists.md`。

## 内容要点

| 部分 | 一句话 |
| --- | --- |
| 核心心法 | 匹配度大于完美度；简历过筛＝人才画像匹配；面试＝持续验真 |
| 招聘漏斗 | 机筛/测评/笔试/初面/中高阶面/HR 面 各自在降低什么不确定性 |
| 简历 | 从 JD 反推；一类岗位一套简历；关键词＋真实证据；做减法删错误画像 |
| 表达框架 | 先结论再展开；项目用"痛点→打法→资源→结果"；结尾回到岗位 |
| 轮次策略 | 初面讲执行，二面讲判断与商业价值，终面讲潜力与格局 |
| 反问 | 按面试官层级选；高级别不问工时福利 |
| Offer | 节奏集中于同一决策窗口；其他 Offer 可策略性披露但不虚构；选择顺序：赛道→岗位→薪酬→城市 |
| 红旗 | 成绩弹性处理、把组员写成队长、虚构 Offer、编造背景、过度做人设——均标注风险与正确做法 |

## 说明与边界

- 原材料来自一场个人分享，其中包含**争议性策略**（如成绩"弹性处理"、虚构其他 Offer）。本 skill 已逐条标注风险并给出更稳妥的做法，**不建议照做**。
- 原分享偏向通用校招（含工科/经管视角）。对非技术岗、AI 产品岗的适配由使用者按 JD 调整。
- 数据与时效：分享会时间为 2026-09-17，涉及校招时间线、HC 逻辑等经验性内容，会随年份变化。

## 更新建议

用一次面试就回来补一次：把新出现的追问补进自己的追问树，把答砸的问题写进复盘。这个方法论的寿命取决于它是否持续被真实面试校准。
